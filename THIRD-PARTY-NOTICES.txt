Library Workbench includes or depends on third-party software.

The project source is provided under the MIT license in LICENSE.
Portable Windows packages include the official CPython embeddable runtime; its
license is supplied in runtime/LICENSE.txt. Third-party Python package metadata
and license files are retained under runtime/Lib/site-packages/*.dist-info.
macOS app bundles retain dependency license metadata collected by PyInstaller.

Core dependencies include Flask, Werkzeug, lxml, pyrekordbox, TinyTag (MIT), markdown-it-py (MIT), mdurl (MIT), SQLAlchemy, NumPy,
psutil and sqlcipher3-wheels, with their transitive dependencies. Build manifests
record the exact versions and, for the Windows wheel assembly, source URLs and
SHA-256 digests. Consult each included package license for its terms.

Product names identify supported data sources or workflow documentation.

The offline bubble explorer bundles d3-hierarchy 3.1.2 (ISC license),
copyright 2010-2021 Mike Bostock. Its complete license and verified npm package
provenance are in static/d3-hierarchy-LICENSE.txt and
static/d3-hierarchy-provenance.json. No CDN or online chart service is used.

The optional MusicBrainz pilot retrieves third-party data into a private local
cache. MusicBrainz core data is CC0; supplementary community ratings and tags
are CC BY-NC-SA 3.0. Retrieved data is not bundled with MIT project source or
application releases. Proposals retain source URLs, retrieval times, vote counts
and license attribution. See https://musicbrainz.org/doc/About/Data_License.
